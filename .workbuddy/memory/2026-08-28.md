## Battle Core 全仓审查（设计 + 实现 + 测试）

产出：`docs/review-2026-08-28.md`（审查报告，18 条问题，按严重度分组）。

方法：读 CONTEXT.md 契约 + 42 份 ADR → 派 3 个 Explore agent 分块审查子系统 → 自己逐条验证 agent 结论 → 写临时探针测试实证 → 删探针、跑全量测试确认仓库干净。

### 实证确认的 bug（写探针跑出来的，不是推测）
1. **弹体隧穿** — `Projectiles.cs:150-193` 只对移动前后两个离散点做命中检测，地形有扫掠、Character 没有。60 m/s（2 m/帧）对 1.4 m 命中窗口直接穿过；6 m/s 对照组命中。
2. **`Tick()` 可被宿主输入打崩** — `FixVector2.NormalizeOrZero` 在向量非零但极短（分量 raw < 256）时 `LengthSquared` 下溢为 0 → `Fix64.operator /` 抛异常。经 `MovementIntent.Direction` 由外部 `MoveDirectionCommand` 可达。
3. **眩晕取消时间轴不彻底** — `Skills.cs:318-355` while 循环用局部 `cast`，不检查 `caster.ActiveSkill` 是否已清空：同帧后续效果照常结算（实证自伤 25 仍生效），最后一帧取消会发 2 个 `SkillEndedEvent`。
4. **尸体回收时飞行中弹体消失** — `Projectiles.cs:252-256`，施法者从 `_characters` 移除即销毁弹体，与 ADR 0042（AreaEffect 创建者死后仍继续）不一致。

### 关键结论（下次接手直接看这些）
- **确定性基础设施是干净的**：零 float/double/Random/Guid/DateTime，实体容器全 `SortedDictionary<long,T>`，RNG 分层派生，JSON 拒绝浮点。
- **唯一发现的确定性隐患**：`Resources.cs:20,29` 遍历 `Dictionary<string,long>` 消耗多资源，.NET 字符串哈希按进程随机化 → 事件顺序不稳定。多资源场景零测试覆盖。
- **最大系统性风险**：确定性（第一设计约束）**零回归测试**。grep 不到任何回放/哈希/一致性验证，123 测试全绿也无法阻止确定性被破坏。
- 项目基线：`dotnet test BattleCore.slnx --configuration Release` → 123 通过 / 0 失败，约 60-150ms。

### 踩过的坑
- 临时探针测试文件 `tests/BattleCore.Tests/_ReviewProbe.cs` 用 `rm` 删除时，沙箱模式下会报 "No such file or directory" 但实际已删除——用 Glob 二次确认，不要重复 rm。
