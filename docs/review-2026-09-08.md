## 一、新发现（按严重度）

### 严重：可打崩 Tick / 永久卡死

1. **复活落点不校验 → 尸体被敌人踩着时复活，双方永久卡死。** `StandUp` 直接置回 Alive。Dead 尸体不参与占用，敌人可站到尸体上；复活后两圆重叠，`FindMovementFraction` 从非法起点采样恒返回 0，任何位移都是 0。N4 已为 Carry 做了落点环形搜索，复活路径没有复用。
2. **`PickupAttributeEffect` 命中模板缺该属性的拾取者 → `ArgumentException` 打崩 Tick。** 配置校验只查属性「已全局声明」；N1 修复覆盖了 Buff 与技能路径，漏了拾取。`Picker: Any` 即可复现。
3. **宿主可控坐标无上界 → 定点平方溢出打崩 Tick。** `MoveToCommand.Destination` 不做边界检查，`DeltaToward` 里 `LengthSquared` 对 1e8 米级距离 `checked` 溢出；`CastSkillCommand.TargetPoint` 只在含 `CircleAtPoint/RingAtPoint` 时检查在图内，Dash / 弹体 / 投掷不检查；超大方向向量归一化同样溢出。
4. **横版：MoveSpeed 被减成负数 + MoveTo → `Fix64.Clamp` 抛 `ArgumentException`。** `HorizontalDelta` 的 `Clamp(delta, -max, max)` 在 `max < 0` 时 min > max。俯视路径不抛但会倒着走。

### 中等：契约违背 / 明显玩法缺陷

5. **横版：ExplicitTarget 近战穿楼板命中。** ADR 0047 射程只看 X，但 `ExplicitTarget`/`CurrentTarget` 没有形状，射程是它们唯一的几何约束。`range: 1` 的单体打击可隔着地形打到 5 米高平台上的目标。
6. **横版：Brain 站在平台下无限空放技能。** 同源。`IsInAttackRange` 用 X 距离 → 停下施法；`BoxAtCaster` 高 2 米打不到 5 米高的目标，200 帧 30+ 次起手 0 命中，烧 CD/资源。
7. **横版：接地只认「顶边精确接触」，靠圆角/敌人头顶停住时永远不接地、不能跳。** `IsSupported` 只匹配 `|bottom − Max.Y| ≤ 2 raw` 且只查地形/边界；用全直径方形足迹判定支撑而碰撞用圆，圆心越过边缘仍算「站着」。ADR 0044 原文写的是「向下探针被挡」，实现漂移。
8. **出生点 leash 可被「站桩」永久瓦解 Brain。** `TryReturnToLeash` 到达判定 `distance ≤ 自身半径`；敌人站在出生点上，怪最多回到一倍直径外，`ReturningToLeash` 恒 true，每帧清目标、跳过 Think。ADR 0035 未覆盖「原点被占」。
9. **Reviving 状态的单位仍是硬墙。** `IsPositionValid` 只放行 Dead；Reviving 不可选中、不受伤、不行动，却照常阻挡敌人移动——一个 `ReviveDelayFrames` 长的无敌路障。需要拍板。
10. **横版：竖直冲量无上限累加。** `ApplyVerticalImpulse` 直接 `+=`；同帧两个 2 米击飞实测顶点 > 9 米。下落有 `MaximumFallSpeed`，上升没有封顶。ADR 0045 未写累加语义。

### 较低：一致性 / 事件 / 边界

11. **Buff `Duration == Interval` 一次都不跳。** `AdvanceBuffs` 到期检查在周期检查之前且都是 `<=`。护盾/区域用「到期帧开头销毁」，弹体多活一帧（N9）——三套帧语义。
12. **`PickupGrantLivesEffect` 改 Lives 不发事件；`PickupAttributeEffect` 加的修饰永久且不可追溯**（无 ModifierSource、无事件）。
13. **横版：死亡/复活倒计时/被携带的单位不受重力。** 空中被击杀的单位悬停成「浮空尸体」；Carry 放下后 `Grounded`/`VerticalVelocity` 沿用旧值。

## 三、设计层判断

1. ADR 0047「gameplay range 只看 X」隐含所有命中都有 2D 形状；单体技能没有，需要补 Y 容差。
2. 横版接地需要明确的「支撑」定义，而不是 2 raw 容差的巧合；应与碰撞解算共用几何。
3. `FindMovementFraction` 从非法起点恒返回 0 是系统性陷阱；进入非法起点的每条路都必须复验落点。
4. 命令入口缺统一的「坐标在图内」守门；契约把「宿主输入不得打崩 Tick」当硬约束，应在 `ApplyCommand` 一处收口。
5. 绑定属性需要下界：`MoveSpeed`、`MaxHP` 被修饰到 ≤ 0 在俯视是荒谬行为，在横版已是异常。

## 四、核对过、未见新问题

Tick 阶段顺序；`SortedDictionary` 遍历序；RNG 派生与流隔离；`Fix64` 全 `checked`；`FacingAttackBox` 四象限边界与横版 `ClampFacing` 自洽；弹体扫掠按 t→id 排序；Carry 眩晕/死亡掉落与同帧跟随；JSON `spatialMode`/`sideView` 解析与 `MapConfig` 校验；样例 bundle 均可加载。
