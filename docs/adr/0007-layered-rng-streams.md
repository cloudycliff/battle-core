# Layered deterministic RNG streams

Randomness (crit, hit rolls, Brain choices, spawns) uses a deterministic PRNG only. CreateBattle(seed) derives layered streams: one battle stream, one combat stream per Character, one AI stream per Character, one stream per AreaEffect, and one stream per Buff instance. A single global cursor was rejected because adding or reordering entities reshuffles unrelated rolls. Reusing a despawned Character's combat stream for lingering areas was rejected because it pins ghost state and couples unrelated crit sequences. Stateless hashing was rejected as V1 primary RNG because multi-roll-per-frame still needs a cursor and is harder to test in isolation.
