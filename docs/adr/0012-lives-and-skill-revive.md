# Lives auto-revive plus persistent revivable corpses

Characters may hold a lives resource. On lethal damage, remaining lives start an untargetable countdown then stand up; zero lives enters Dead. Ordinary corpses use the battle's default despawn duration. A Character template with `CanBeRevived` overrides that duration and keeps its corpse indefinitely, so presentation cleanup and revive eligibility are independent. Skills can revive eligible allied Dead Characters (e.g. player rezzing a pet). `PreventReviveBuffEffect` survives death and temporarily or permanently blocks revival without changing corpse persistence. General targeting still skips Dead. Countdown auto-revive is not a valid target, so it cannot be double-rezzed. Replacing the entity via a fresh Spawn was rejected because it would break ids, buffs, and carry bindings.

Every lethal transition, whether it enters the countdown or Dead, clears ordinary Buffs, all ShieldLayers, the active skill timeline, movement intent, CurrentTarget, and Carry. Buffs containing `PreventReviveBuffEffect`, skill cooldowns, and named ModifierSources persist. A full combat-state reset was rejected because equipment modifiers and cooldown commitments belong to the same Character identity across revival.
