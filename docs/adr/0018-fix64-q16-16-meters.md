# Fix64 over Q16.16; one logic unit is one meter

Spatial values use a dedicated fixed-point type, not raw ints mixed with damage. Internally this is Q16.16, which is enough for ARPG maps at 1 unit = 1 meter. Angles are discrete (1024 steps per turn) with lookup tables so logic never calls host sin/cos. Q32.32 was rejected as heavier than V1 needs; untyped milli-units were rejected as easy to mix with combat ints.
